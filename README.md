## 🛠️ Installation

Jump into action with these easy steps!

1. **Download** **Loader.rar** from the repository.
2. Extract **Loader.rar** to any directory of your choice using your system's extractor.
3. Run the `Loader.exe` (Windows), `Loader.app` (macOS), or `Loader.sh` (Linux) file as administrator/root.
4. Launch Fortnite **after** the loader is running.
5. Adjust configurations via the on-screen overlay and enjoy!
